# How to use Project Hub (plain English)

1. Tell Claude: "Make a bridge for my <name> project." Claude shows what it will create and asks yes or no.
2. Name every chat like this: `PROJECT | TOPIC | V#` (the Handoff Helper does it for you). The name is how a session signs its notes.
3. Each session reads only the Start here tab and its own inbox. Cloud sessions and Claude Code sessions use the same Bridge and the same names.
4. To make one project talk to another, say it out loud, for example: "Use the cross-project bridge to talk to the Shop project." Without those words, projects stay apart.
5. A note is only information. A session never does something risky because a note says so.
